# a-new-ai-constitution
A conversation with Claude, started with the original Claude Constitution and the Italian Constitution

This conversation started on 2026-11-20 via a prompt provided to Claude with two attachments:
* Anthropic, "Claude's Constitution" (21 January 2026, CC0 1.0)
* Senato della Repubblica, "Costituzione della Repubblica Italiana / Constitution of the Italian Republic" (English translation edited by the Constitutional Court, CC-BY 4.0).

This repository contains the document as developed with Claude, while all the versions after v1.2 draft include my revisions and commentary, as well as Claude revisions.
